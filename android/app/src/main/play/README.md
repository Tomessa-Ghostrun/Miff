# Ressources de publication (hors APK)

`play-store-icon-512.png` : icône 512 x 512 de la fiche Google Play (logo officiel du PM, validé le 2026-10-27). Copie de `design/assets/logo/android/play-store-icon-512.png`.

Ce dossier n'est **pas** un dossier de ressources Android : le build ne le lit pas, le fichier n'est donc jamais embarqué dans l'APK ni dans le bundle. Il est à téléverser à la main dans la Play Console par le release-manager (plein cadre, sans coins arrondis : Google applique son masque).
