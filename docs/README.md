# docs/

Dépose ici tes notes brutes, exports Notion (markdown ou PDF), ou idées de fonctionnalités en vrac. L'agent `product-specs` les transformera en specs structurées dans `docs/specs/`.

Sous-dossiers générés au fil du projet :
- `specs/` — specs par fonctionnalité (créé par l'agent `product-specs`)
- `qa/` — checklists de test et bugs connus (créé par l'agent `qa-tester`)
- `release/` — checklists de soumission stores (créé par l'agent `release-manager`)
