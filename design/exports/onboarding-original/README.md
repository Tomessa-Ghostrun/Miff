# Maquettes d'origine de l'onboarding (exports PNG du PM)

Source : export PNG des cadres Figma du fichier original « Miff - App » (fileKey Byi9NgQxkBPbmbhU403HSf), fourni par le PM le 2026-10-28 (fichier « Miff - App.zip »). Ce sont les maquettes de référence que les tickets Notion lient : l'implémentation doit y être plutôt FIDÈLE, avec de petits ajustements justifiés (voir les tickets et les décisions du PM : tutoiement, deux cases de consentement, libellés « Continuer avec… », etc.).

Résolution : environ 320 x 640 px, une capture par écran. Les noms de fichiers sont ceux de Figma (« Welcoming screen-N »), sans signification.

Repères identifiés (liste à compléter par le design-system) :
- Welcoming screen : carrousel de bienvenue (3 slides : -16 et -17 sont les slides 2 et 3)
- -1 : profil (photo, prénom, nom) ; -2 : téléphone ; -6 : téléphone avec erreur
- -3, -4, -5 : choix créer / rejoindre une Miff (vide, rempli, code invalide)
- -7 : inscription ; -18 : nouvelle Miff ; -19 : amorce de notifications
- Paywall.png : paywall ; mdi-light_eye.png : icône œil du champ mot de passe

Les droits sur les images du carrousel (photos de personnes) sont à vérifier avant publication : ce sont des photos de banque d'images selon l'analyse du ticket Onboarding.
