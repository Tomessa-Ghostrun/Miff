PNG @2x rendus depuis les HTML de `design/screens/update/mockups/` (390 pt de large, planches plus larges pour plusieurs états). Ce ne sont **pas** des exports Figma : les maquettes du PM restent dans `design/exports/update/Welcoming screen*.png`. Le rendu « liquid glass » d'iOS 26 est une approximation : le vrai rendu est celui du système.
