# design/

Dépose ici tes exports Figma : captures d'écran, PDF, valeurs copiées depuis le mode Dev de Figma (couleurs, tailles, espacements), ou simplement une description manuelle si l'export n'est pas possible.

L'agent `design-system` les transformera en documentation exploitable par les agents `ios-dev` et `android-dev` (`design-system.md` et `screens/`).
